# CLI reference

Every `prism` command, as `prism <command> --help` prints it. Generated by
`make docs-reference`.

```text
Usage: prism [OPTIONS] COMMAND [ARGS]...

 PRism: repo-aware code review.

+- Options ---------------------------------------------------------------------------------------+
| --install-completion        <bool>  Install completion for the current shell.                   |
| --show-completion           <bool>  Show completion for the current shell, to copy it or        |
|                                     customize the installation.                                 |
| --help                      <bool>  Show this message and exit.                                 |
+-------------------------------------------------------------------------------------------------+
+- Commands --------------------------------------------------------------------------------------+
| index      Index a repo and print graph stats. The commit comes from git, else "working-tree".  |
| context    Ranked context for each hunk of a diff, with token counts.                           |
| review     Review a diff and print a validated PRReview as JSON.                                |
| mcp        Serve PRism's review tools over MCP on stdio (needs `uv sync --group mcp`).          |
| dashboard  Serve the dashboard on 127.0.0.1:PORT (needs `uv sync --group app`, and the page     |
|            built                                                                                |
|            with `npm ci && npm run build` in dashboard/).                                       |
| graph      Query the code graph. Reads the persistent store by default; with --path, indexes    |
|            that folder in memory first and answers from that.                                   |
| prompts    Prompts in Langfuse prompt management.                                               |
| app        The GitHub App (needs `uv sync --group app`).                                        |
| bench      BugBench: planted-defect PRs and recall.                                             |
+-------------------------------------------------------------------------------------------------+
```

## `prism context`

```text
Usage: prism context [OPTIONS] {repo} {diff}

 Ranked context for each hunk of a diff, with token counts.

+- Arguments -------------------------------------------------------------------------------------+
| *    repo      <dir>  Checkout of the PR head commit. [required]                                |
| *    diff      <str>  Unified diff file, or - for stdin. [required]                             |
+-------------------------------------------------------------------------------------------------+
+- Options ---------------------------------------------------------------------------------------+
| --repo-id         <str>                  Repo id. Defaults to the folder name, or the only repo |
|                                          in the persistent store.                               |
| --mode            <str>                  none, vector, graph or graph+vector. Default           |
|                                          PRISM_CONTEXT_MODE.                                    |
| --budget          <int range> [x>=50]    Tokens per hunk.                                       |
| --hops            <int range> [1<=x<=2]                                                         |
| --store           <str>                  persistent: base graph from Neo4j/pgvector for the     |
|                                          repo id. memory: index this tree in memory, so the     |
|                                          base equals the head (deleted symbols lose their       |
|                                          callers, and vector modes embed the whole repo first). |
| --reranker        <str>                  cross-encoder, overlap or none.                        |
| --json            <bool>                 Print the bundle as JSON.                              |
| --render          <bool>                 Print the text block a prompt would include.           |
| --help            <bool>                 Show this message and exit.                            |
+-------------------------------------------------------------------------------------------------+
```

## `prism review`

```text
Usage: prism review [OPTIONS]

 Review a diff and print a validated PRReview as JSON.

 With the handoff verifier (the default) the first run stops with exit code 2 after writing
 verifier requests into the work directory; a Claude model writes the answers (see the rubrics
 there), and running the same command again finishes the review.

+- Options ---------------------------------------------------------------------------------------+
| *  --repo                       <dir>                 Checkout of the PR head commit.           |
|                                                       [required]                                |
| *  --diff                       <str>                 Unified diff file. [required]             |
|    --out                        <path>                Write the PRReview JSON here too.         |
|    --work                       <path>                Work directory for cached replies and     |
|                                                       verifier batches. Default                 |
|                                                       PRISM_REVIEW_WORK_DIR/<repo>-<sha>-<diff  |
|                                                       hash>.                                    |
|    --verifier                   <str>                 handoff, api or rules. Default            |
|                                                       PRISM_VERIFIER.                           |
|    --model                      <str>                 Reviewer model. Default                   |
|                                                       PRISM_REVIEWER_MODEL.                     |
|    --max-hunks                  <int range> [x>=1]    Default PRISM_REVIEW_MAX_HUNKS.           |
|    --time-limit                 <float range> [x>=1]  Seconds. Default                          |
|                                                       PRISM_REVIEW_TIME_LIMIT_S.                |
|    --store                      <str>                 persistent or memory, for the verifier's  |
|                                                       context.                                  |
|    --mode                       <str>                 Context mode for the verifier. Default    |
|                                                       PRISM_CONTEXT_MODE.                       |
|    --repo-id                    <str>                 Repo id. Defaults to the folder name, or  |
|                                                       the only repo in the persistent store.    |
|    --pr                         <int range> [x>=1]                                              |
|    --no-sast                    <bool>                Skip static analysis (PRISM_SAST_TOOLS).  |
|    --save          --no-save    <bool>                Store the review in Postgres              |
|                                                       (PRISM_REVIEW_STORE).                     |
|                                                       [default: save]                           |
|    --help                       <bool>                Show this message and exit.               |
+-------------------------------------------------------------------------------------------------+
```
